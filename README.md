## Featured Project

### Employee Lifecycle Sync

HR 직원 정보를 내부 DB와 동기화하고,  
입사·정보 변경·퇴사에 따른 그룹웨어 계정 연계를 관리하는 시스템입니다.

- 외부 시스템 장애와 내부 직원 처리 분리
- 실패 작업 자동 재처리 및 복구
- 동일 요청의 중복 처리 방지
- 10,000건 동기화 조회 구조 개선
- AWS 배포 및 GitHub Actions 자동화
